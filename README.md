# Diabetes Prediction

## 📌 Problem Statement

Diabetes merupakan kelainan metabolisme yang ditandai dengan tingginya kadar gula darah dalam jangka waktu lama. Gejalanya antara lain sering buang air kecil, rasa haus yang meningkat, dan rasa lapar yang meningkat. Jika tidak diobati, diabetes dapat menyebabkan komplikasi serius.

Diagnosis diabetes tidak selalu mudah karena gejalanya bisa samar dan memerlukan tes laboratorium yang mahal. Oleh karena itu, project ini bertujuan untuk membangun model prediksi diabetes berdasarkan data medis yang tersedia, dengan pendekatan machine learning.

## 📊 Dataset

Dataset yang digunakan bernama `diabetes_prediction_dataset.csv`. Dataset ini berisi fitur-fitur seperti:
- Age
- Gender
- BMI
- Blood Glucose Levels
- Smoking Status
- Hypertension
- Heart Disease
- etc.

## 🧪 Model Development

Langkah-langkah utama dalam notebook:
1. Data preprocessing (handling missing values, encoding, scaling)
2. Exploratory Data Analysis (EDA)
3. Feature Selection
4. Model training dengan beberapa algoritma:
   - Logistic Regression
   - Random Forest
   - Support Vector Machine (SVM)
5. Model Evaluation dengan metrik:
   - Accuracy
   - Precision
   - Recall
   - F1-score
   - Confusion Matrix

## 📈 Hasil

Model dengan performa terbaik ditentukan berdasarkan evaluasi komparatif. Visualisasi performa juga disertakan untuk memperkuat interpretasi hasil.
